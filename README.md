# Pizza House 🍕

A premium, fully responsive, and modern restaurant landing page designed to provide a seamless browsing experience across all devices. Built from scratch using semantic HTML5 and custom CSS3.

## 🚀 Live Demo
You can view the live project here:  
👉 [Live Project Link]( https://akashraval3709-prog.github.io/Python-to-Cyber-Journey/)



## 🚀 Features

- **Sleek Sticky Navigation:** Fully operational navigation bar that remains locked at the top during scrolling for easy accessibility[cite: 3, 4].
- **Dynamic Image Zoom Effect:** Beautiful, smooth CSS animations (`transform: scale`) applied to the hero imagery on hover[cite: 4].
- **Grid-Based Card Layouts:** Structured CSS Grid showcases popular food items and a interactive menu display[cite: 4].
- **Interactive Component States:** Premium hover effects (`translateY`, custom shadows) built into call-to-action buttons and feature cards[cite: 4].
- **100% Mobile Responsive:** Optimized with tailored CSS Media Queries to ensure precise alignment, spacing, and element scaling on mobile displays[cite: 4].

## 🛠️ Tech Stack Used

- **HTML5:** Semantic architecture (`header`, `section`, `footer`).
- **CSS3:** Flexbox, CSS Grid, Media Queries, Transitions, and Custom Keyframes[cite: 4].
